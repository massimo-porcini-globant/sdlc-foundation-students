# docs/

Your project documentation. Across the course you will produce, among others:

- `project-brief.md` — the pre-built Project Brief, copied from `templates/project-brief.md` (session 0).
- `skill-teardown-<skill>.md` — skill teardowns, copied from `templates/skill-teardown-template.md` (session 3).
- `adrs/` — Architecture Decision Records (sessions 5-7), from `templates/adr-template.md`.
- `standards.md`, `reviewer-log.md`, `audit/` — quality artifacts (session 7).

Note: your Architecture Specification Document (ASD) and your implementation plans do **not** live here — the harbor skills write them to `.globant-skills-docs/` (`asd/` in session 1, `plans/` from session 2), one level up. Version that folder too.

Keep this documentation versioned alongside your code — it is part of your assessable work.
